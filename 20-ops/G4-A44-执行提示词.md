# Gate 4 · A-44 执行提示词：把今天跑通的链路固化成开机自启

> 2026-11-01 09:07 已实测达成：**桌面在核显上 GPU 合成**（`iop_ok` 39 帧/秒、`Resolution 3120x2080 Online Yes`、
> 液态玻璃效果可见）。但整条链路是**运行期四步**搭起来的：
>
> ```
> load core → stage=7 → load accel → debug.xegfxaccelfb=3 → debug.xegfxaccel_iop=1
> ```
>
> **重启即全部丢失。** 本关把它做成开机自启。

---

## 0. 已实测的成功配方（本关要固化的就是它）

```bash
sudo /usr/bin/kmutil load -b org.watchthelight.XeGfx
sudo sysctl -w debug.xegfx_wdog=60
sudo sysctl -w debug.xegfx_stage=7
sleep 22
sudo /usr/bin/kmutil load -b org.watchthelight.XeGfxAccel
sudo sysctl -w debug.xegfxaccelfb=3        # scanout-backed display pipe ENABLED
sudo sysctl -w debug.xegfxaccel_iop=1      # transaction hooks OPEN ← 关键的一步
```

验收读数（当时的原值）：

```
debug.xegfxaccel_iop_ok  1904 → 2098 (+194 / 5 s ≈ 39 fps)
debug.xegfxaccel_iop_fail 0
debug.xegfxaccel_iop_empty 0
system_profiler: Resolution 3120 x 2080 / Main Display: Yes / Online: Yes
```

### 0.1 关键教训（决定自启的时机）

| 教训 | 出处 |
| --- | --- |
| **不要在 boot 阶段推 stage 7 / 切呈现** | A-25b：WS `push_surface` 断言 + 登录回环 |
| `accelfb` 必须写 **3**（写 1 只 armed，不开 scanout） | `nvrm-accel.cpp:764` `how >= 3` |
| `iop=1` 必须在 `accelfb=3` **之后** | 否则 pipe 还没开，事务没对象 |
| `scanout-backed display pipe ENABLED` 之后**不需要重启 WS** | A-42/A-43 现场实测：开闸后立刻出画面 |

→ 自启脚本必须**等桌面稳定后再动手**，而不是在 boot 早期。

## 1. 写自启脚本

```bash
sudo tee /usr/local/bin/xegfx-bringup.sh >/dev/null <<'EOF'
#!/bin/bash
# XeGfx bring-up: core -> stage 7 -> accel -> scanout pipe -> transaction hooks.
# Runs AFTER a console user exists and the desktop has settled (A-25b: doing this at
# boot made WindowServer assert).  Every step is checked; on failure it stops and
# leaves the machine on the firmware framebuffer, which is the safe state.

LOG=/var/log/xegfx-bringup.log
STATE=/var/db/xegfx
mkdir -p "$STATE"
log() { printf '%s %s\n' "$(date '+%Y-%m-%d %H:%M:%S')" "$*" >> "$LOG"; }

K=/usr/bin/kmutil
[ -x "$K" ] || K=/usr/sbin/kmutil

# 1) wait for a real console user (loginwindow = root here)
for i in $(seq 1 300); do
  u=$(stat -f %Su /dev/console 2>/dev/null)
  if [ -n "$u" ] && [ "$u" != "root" ] && [ "$u" != "_mbsetupuser" ]; then
    log "console user=$u after ${i}s"; break
  fi
  sleep 1
done
u=$(stat -f %Su /dev/console 2>/dev/null)
if [ -z "$u" ] || [ "$u" = "root" ]; then log "no console user after 300s -- abort"; exit 1; fi

# 2) let the desktop finish settling (WindowServer first paint)
sleep 25

# 3) core
if ! $K showloaded 2>/dev/null | grep -q org.watchthelight.XeGfx; then
  $K load -b org.watchthelight.XeGfx || { log "load core FAILED"; exit 2; }
  log "core loaded"
fi
sleep 3

# 4) stage 7
sysctl -w debug.xegfx_wdog=60 >/dev/null 2>&1
sysctl -w debug.xegfx_stage=7 >/dev/null 2>&1
for i in $(seq 1 40); do
  r=$(sysctl -b debug.xegfx_results 2>/dev/null | od -A n -t d4 | tr -s ' ' | sed 's/^ //')
  case "$r" in
    "0 1 1 1 1 1 1 1") log "stages ok: $r"; break ;;
  esac
  sleep 1
done
r=$(sysctl -b debug.xegfx_results 2>/dev/null | od -A n -t d4 | tr -s ' ' | sed 's/^ //')
[ "$r" = "0 1 1 1 1 1 1 1" ] || { log "stages NOT ok: $r -- abort"; exit 3; }

# 5) accel
if ! $K showloaded 2>/dev/null | grep -q org.watchthelight.XeGfxAccel; then
  $K load -b org.watchthelight.XeGfxAccel || { log "load accel FAILED"; exit 4; }
  log "accel loaded"
fi
sleep 4

# 6) scanout pipe  (how>=3 -- writing 1 only arms, it does NOT open the pipe)
sysctl -w debug.xegfxaccelfb=3 >/dev/null 2>&1
sleep 3
if ! log show --last 60s --predicate 'eventMessage CONTAINS "scanout-backed display pipe ENABLED"' 2>/dev/null | grep -q ENABLED; then
  log "WARN: pipe-ENABLED line not seen in the last 60s (continuing)"
fi

# 7) transaction hooks  -- this is the one that makes frames reach the panel
sysctl -w debug.xegfxaccel_iop=1 >/dev/null 2>&1
sleep 3

a=$(sysctl -n debug.xegfxaccel_iop_ok 2>/dev/null); sleep 3
b=$(sysctl -n debug.xegfxaccel_iop_ok 2>/dev/null)
log "iop=1  iop_ok $a -> $b"
if [ "${b:-0}" -gt "${a:-0}" ]; then log "OK: frames are reaching the panel"; exit 0; fi
log "WARN: iop_ok did not advance (panel keeps the firmware frame)"
exit 5
EOF
sudo chmod 755 /usr/local/bin/xegfx-bringup.sh
sudo bash -n /usr/local/bin/xegfx-bringup.sh && echo SYNTAX-OK
```

**门 1：`SYNTAX-OK`。** 不过关就贴 `bash -n` 的输出，别继续。

## 2. 装 LaunchDaemon

```bash
sudo tee /Library/LaunchDaemons/org.xegfx.bringup.plist >/dev/null <<'EOF'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>            <string>org.xegfx.bringup</string>
    <key>ProgramArguments</key>
    <array><string>/usr/local/bin/xegfx-bringup.sh</string></array>
    <key>RunAtLoad</key>        <true/>
    <key>StandardOutPath</key>  <string>/var/log/xegfx-bringup.out</string>
    <key>StandardErrorPath</key><string>/var/log/xegfx-bringup.err</string>
    <key>ProcessType</key>      <string>Background</string>
</dict>
</plist>
EOF
sudo chown root:wheel /Library/LaunchDaemons/org.xegfx.bringup.plist
sudo chmod 644 /Library/LaunchDaemons/org.xegfx.bringup.plist
plutil -lint /Library/LaunchDaemons/org.xegfx.bringup.plist
sudo launchctl bootstrap system /Library/LaunchDaemons/org.xegfx.bringup.plist 2>&1 || \
  sudo launchctl load -w /Library/LaunchDaemons/org.xegfx.bringup.plist 2>&1
sudo launchctl print system/org.xegfx.bringup 2>/dev/null | head -8
```

**门 2：`plutil -lint` OK、`launchctl print` 能看到该 job。**

> ⚠️ 刚 bootstrap 时机器已在跑，脚本会**等 300 秒找控制台用户**（已满足）+ 等 25 秒 + 再跑一遍四步。
> 若它立刻又执行一次 `accelfb=3`/`iop=1`，对已生效的状态是**幂等**的（源码里只是重复置位），不会坏。
> 想立刻看它跑：`sudo launchctl kickstart -k system/org.xegfx.bringup`，然后 `tail -f /var/log/xegfx-bringup.log`。

## 3. 判决：重启一次，全自动

```bash
sudo reboot
```

回来后等登录（**必须真人登录**，脚本靠 `/dev/console` 判定）：

```bash
# 等脚本跑完（最多 7 分钟）
for i in $(seq 1 84); do
  grep -q "OK: frames are reaching the panel\|WARN: iop_ok did not advance\|abort" /var/log/xegfx-bringup.log 2>/dev/null && break
  sleep 5
done
echo "=== bringup.log ==="; sudo cat /var/log/xegfx-bringup.log
echo "=== 计数 ==="; for k in iop iop_ok iop_fail; do printf "%-8s %s\n" "$k" "$(sudo sysctl -n debug.xegfxaccel_$k 2>/dev/null)"; done
echo "=== 显示 ==="; system_profiler SPDisplaysDataType 2>/dev/null | grep -E "Resolution|Online|Main Display"
```

**门 3（本关成功）：`bringup.log` 末行是 `OK: frames are reaching the panel`，且 `iop_ok` 在增长、`
`Resolution 3120 x 2080 / Online: Yes`。** 再加**用户目视确认桌面正常**（这是最终判据）。

## 4. 顺带测一次"卡"的程度（为下一关留基线）

```bash
L=~/xegfx-log/A-44; mkdir -p $L
```

## 5. 失败处理

| 现象 | 动作 |
| --- | --- |
| 登录后屏幕一直是启动文本 | 看 `bringup.log` 停在哪一步；`exit 2/3/4` 分别对应 core/stages/accel |
| 屏幕花屏/黑屏 | 立即 `sudo sysctl -w debug.xegfxaccel_iop=0`；仍不行则 `sudo nvram ...` 清门 + 重启 |
| `iop_ok` 不增长 | 贴 `bringup.log` 与 `log show --last 5m --predicate 'eventMessage CONTAINS "NMXAccel"'` 中 `iop:` 相关行 |
| 脚本没跑 | `sudo launchctl print system/org.xegfx.bringup` 看 `last exit code` |

**一键停用**（保留文件，不删）：

```bash
sudo launchctl bootout system/org.xegfx.bringup 2>/dev/null
sudo sysctl -w debug.xegfxaccel_iop=0
```

## 7. 铁律

1. 自启必须**等登录 + 25 秒**再动手（A-25b 的教训：boot 早期切呈现会让 WS 断言）。
2. 顺序不可换：`core → stage7 → accel → accelfb=3 → iop=1`。
3. 脚本幂等：已加载/已置位就跳过，不重复 load。
4. 任何一步失败就**停在那一步**并退出，不硬推后续步骤 —— 保持机器可用。
5. 判据以**用户目视**为准，`screencapture` 在 SSH 下不可用。
