# Gate 4 执行提示词 · 桌面合成跑在核显（A-16 / A-17）

> 用法：把本文件全文作为一条消息发给执行会话。执行会话不需要任何前置上下文。
> **本关两步：先让加速器 attach（A-16），再看 WindowServer 是否真的用它（A-17）。**
> **A-17 才是本关的分水岭 —— 历史上 `vmmap WindowServer | grep -c NVMTL` 一直是 0。**

## 0. 目标

**验收（四条全中才算"真加速"）**

| # | 检查 | 期望 |
| --- | --- | --- |
| 1 | 加速器已 attach | `ioreg -c NMXAccel -l -w0` → 1 个实例，`MetalPluginName` 指向 **NVMTLDriver** |

**第 2 条是分水岭。** 如果它仍是 0，本关判定"未达成"，转 A-18（GGTT flip 方案），不要在第 1/3/4 条上纠缠。

## 2. ⚠️ 一个必踩的雷：备份里的加速器指向了不存在的插件

主 agent 已经把本机所有加速器版本翻了一遍：

```
~/src/out-accel2..6/XeGfxAccel/26/XeGfxAccel.kext   （5 个版本，21:12–21:50 构建）
~/_xegfx-old-20261030/LE/XeGfxAccel.kext            （21:50）
```

**全部**都是：
```
MetalPluginName      = ../../../Library/GPUBundles/XeMTLDriver     ← 这个 bundle 根本不存在
MetalPluginClassName = XeMTLDevice
```
这是 10-30 21:00 之后 ArrowWhatever 路线的残留。而 Gate 2 装的是 **NVMTLDriver**（`com.nullmoth.NVMTLDriver`，
含 `air-runtime/libLLVM.dylib`）。**直接装上去，Metal 通路必断**，而且会表现成"加速器没生效"，白烧一次开机。

**必须先把这两个键改回**（这正是 10-30 15:30 跑通 Metal 16/16 时的配置）：
```
MetalPluginName      = ../../../Library/GPUBundles/NVMTLDriver
MetalPluginClassName = NVMTLDevice
```

## 3. 第二个前置：2 处 `idr_preload` 补丁（防 panic，不是实验变量）

历史记录：`idr_preload` 在禁抢占上下文里 `malloc`，`kmem` 互斥争用即 panic ——
由 `iconservicesagent` 打开加速器的 DRM 客户端时触发。装加速器**之前**必须先补。

主 agent 已核对当前二进制在两位移处的字节，**与预期完全一致，可直接打**：

| 偏移 | 当前字节 | 改成 |
| --- | --- | --- |
| `0x6edf0` | `e8 2b cd 02 00`（`call rel32`） | `90 90 90 90 90` |
| `0x6ef36` | `e9 05 cc 02 00`（`jmp rel32`） | **`c3`** + `90 90 90 90` |

> **尾部必须是 `c3`（ret），不能填 5 个 NOP** —— 10-30 用 NOP 打过一次，直接启动 panic，靠 U 盘 `-x` 救回。

## 4. 铁律

- 一次开机只改一个变量：**A-16 = 补丁 + 装加速器**；**A-17 = 开 AGDC**；**A-18 = 换 flip 栈**。不许合并。
- 装/换 kext 后**必须重启**才能生效；重建 AuxKC 只用
  `sudo kmutil install --volume-root / --allow-missing-kdk -v`。
- **`kmutil` 打印 `rebuild done` 不可信**（已踩三次）：判据是 AuxKC 的 `shasum` 变了 **且**
  `kmutil inspect` 里逐条 id 都在。必要时补一次 `sudo kmutil load -z -p <kext>` 强制重建。
- **重启前必须逐条核对 AuxKC 含 `IGPUConsoleRange`**（这条救过两次场；丢了它 = 黑屏）。
- 每次重启前 `touch /var/db/xegfx/armed`。
- **先不开** `debug.xegfxaccelfb` / `debug.xegfxaccel_iop`（历史上一开 WindowServer 就退出）。
- 不动 OpenCore / boot-args / GPUBundles / 显示几何；不改 `fbgeom` 相关的东西。
- 遇到计划外现象：停手、留证、报告。

## 5. A-16：打补丁 + 装加速器（一次开机）

### 5.1 备份 + 打 2 处补丁

```bash
F=/Library/Extensions/XeGfx.kext/Contents/MacOS/XeGfx
mkdir -p ~/xegfx-log/A-16
sudo cp -p "$F" ~/xegfx-log/A-16/XeGfx.before-idr
sudo shasum -a 256 "$F" | tee ~/xegfx-log/A-16/before.sha

# 逐字节校验后再改（不匹配就停手）
sudo xxd -s 0x6edf0 -l 5 -p "$F"     # 必须 e82bcd0200
sudo xxd -s 0x6ef36 -l 5 -p "$F"     # 必须 e905cc0200
```

用 python 打（不要用 dd 手写偏移）：
```bash
sudo python3 - "$F" <<'PY'
import sys
p = sys.argv[1]
b = bytearray(open(p, 'rb').read())
pat = [(0x6edf0, bytes.fromhex('e82bcd0200'), b'\x90'*5),
       (0x6ef36, bytes.fromhex('e905cc0200'), b'\xc3' + b'\x90'*4)]
for off, exp, rep in pat:
    cur = bytes(b[off:off+len(exp)])
    if cur == rep:
        print('already', hex(off)); continue
    if cur != exp:
        raise SystemExit('MISMATCH @%#x got %s' % (off, cur.hex()))
    b[off:off+len(rep)] = rep
    print('patched', hex(off))
open(p, 'wb').write(b)
PY
sudo codesign --force --sign - /Library/Extensions/XeGfx.kext && sudo codesign -v /Library/Extensions/XeGfx.kext && echo SIGN-OK
```

### 5.2 装加速器（先修 Metal 插件指向！）

```bash
SRC=~/_xegfx-old-20261030/LE/XeGfxAccel.kext
sudo cp -R "$SRC" /Library/Extensions/XeGfxAccel.kext
P=/Library/Extensions/XeGfxAccel.kext/Contents/Info.plist
sudo /usr/libexec/PlistBuddy -c "Set :IOKitPersonalities:NMXAccel:MetalPluginName ../../../Library/GPUBundles/NVMTLDriver" "$P"
sudo /usr/libexec/PlistBuddy -c "Set :IOKitPersonalities:NMXAccel:MetalPluginClassName NVMTLDevice" "$P"
sudo plutil -lint "$P"
sudo plutil -p "$P" | grep -E "MetalPlugin"     # 必须看到 NVMTLDriver / NVMTLDevice

sudo find /Library/Extensions/XeGfxAccel.kext -name '._*' -delete
sudo xattr -cr /Library/Extensions/XeGfxAccel.kext
sudo chown -R root:wheel /Library/Extensions/XeGfxAccel.kext
sudo chmod -R 755 /Library/Extensions/XeGfxAccel.kext
```

> 若 `Set` 报 key 不存在，先 `plutil -p` 看清 personality 的真实名字（可能是 `NMXAccel` 之外的键名），
> **用真实键名，不要新建一个**。

### 5.3 重建 + 校验 + 重启

```bash
sudo kmutil install --volume-root / --allow-missing-kdk -v
shasum -a 256 /Library/KernelCollections/AuxiliaryKernelExtensions.kc | tee ~/xegfx-log/A-16/aux.sha
sudo kmutil inspect 2>/dev/null | grep -A12 "auxiliary kext"
# 必须看到：XeGfx(0.0.46) / XeGfxAccel / IGPUConsoleRange / HighPointRR / HighPointIOP / （XeDiag、XeNative 可选）
# 缺 IGPUConsoleRange → 不许重启
touch /var/db/xegfx/armed && sudo reboot
```

### 5.4 开机后验证

```bash
sudo sysctl -w debug.xegfx_wdog=60 ; sudo sysctl -w debug.xegfx_stage=7 ; sleep 25
sudo sysctl -b debug.xegfx_results | od -A n -t d4          # 期望 0 1 1 1 -28 1 1 1
sudo kmutil showloaded | grep -iE "xegfx(accel|agdc)"
ioreg -c NMXAccel -l -w0 | grep -E "MetalPluginName|MetalPluginClassName|IOAccelRevision|AccelCaps"
~/xegfx-probes/mtlprobe            # 期望 MTLCopyAllDevices count = 1、16/16
system_profiler SPDisplaysDataType | grep -iE "Metal|Resolution"
pgrep -x WindowServer
ls -lt /Library/Logs/DiagnosticReports/*.panic | head -2
```

**A-16 通过线**：`NMXAccel` 有 1 个实例 + `MetalPluginName` 指向 NVMTLDriver + `mtlprobe` 16/16 + `Metal Support` 出现。
**注意**：`mtlprobe` 若因 `IOServiceOpen` 泄露报错，先 `sudo kmutil unload -b org.xenative.XeNative` 再 `load`，或直接重启。

## 6. A-17：看 WindowServer 到底用没用（本关分水岭）

**只有 A-16 全绿才做这一步。**

```bash
sudo vmmap "$(pgrep -x WindowServer)" 2>/dev/null | grep -ci nvmtl | tee ~/xegfx-log/A-17/vmmap-nvmtl.txt
sudo powermetrics --samplers tasks -n 1 2>/dev/null | grep -A3 -i windowserver
system_profiler SPDisplaysDataType | grep -i metal
```

判读：

| `vmmap ... grep -c NVMTL` | 含义 | 下一步 |
| --- | --- | --- |
| **> 0** | ✅ 插件进了 WS → 再看 powermetrics 是否 < 25%；两者都好 = **Gate 4 达成** | 收尾报告 |
| **= 0** | 呈现路径拿不到 map（`IOPresentment: Unable to acquire map`），WS 退回 `CA::OGL::SW` | **停手**，报告，转 A-18 |

同时抓这三条证据（无论结果）：
```bash
sudo log show --last 10m --predicate 'eventMessage CONTAINS "Presentment" OR eventMessage CONTAINS "NVMTL" OR eventMessage CONTAINS "AGDC"' | tail -40
sudo log show --last 10m --predicate 'process == "WindowServer"' | grep -iE "metal|accel|assert" | tail -20
```

## 8. 停机条件

| 现象 | 处置 |
| --- | --- |
| 打补丁时字节 MISMATCH | 停手，报告（说明二进制不是预期版本） |
| AuxKC 缺 `IGPUConsoleRange` | 不重启，回滚 AuxKC，报告 |
| 装加速器后**启动 panic** | 护栏会在下次开机 attempts=2 时自动回滚；若仍起不来 → U 盘 `D:\EFI` 启动，恢复 `~/xegfx-log/A-16/XeGfx.before-idr` 并重建 KC |
| `mtlprobe` 返回 0 设备 | 报告，并附 `ioreg -c NMXAccel` 与 `log show` 里 nvmtl 的加载记录（区分"加速器没 attach"还是"插件被拒载"） |
| WindowServer 退出 / 黑屏但 SSH 在 | 停手，`sudo launchctl kickstart -k system/com.apple.WindowServer` 或重启；报告 |
