## 1. 铁律

1. 使用者在场，**预留半天**；备份 `~/xegfx-log/A-83/backup/`。
   **装机二进制只备份一次**（A-90 §4.1：重复覆盖 `.before` 导致无法回滚）。
2. **FB 的特殊性**：装机 FB 是 **A-60 版**（`d4c74c03…`），源码 = `20-ops/A-90/intelfb-a60-source.cpp`，
   **不是**任何 `~/src` 树里的 intelfb.cpp。备份二进制并把该源码一并归档。
3. accel 装机件 `e51946c8…`（A-89 观测版），源码在 `~/xegfx-log/A-89/tree-tl/`。
4. NMI 协议；装完必看 `kmutil showloaded | grep watchthelight.XeGfxAccel`（A-89 的静默失败坑）；
   黑屏先重启一次再判断。
5. **每级装机后验 AGDC 绑定**：`ioreg -l -w0 -c XeGfxAGDCLoader`，出现 `pci 0x0 fb 0x0`
   就是 AGDC 静默失配（README 结论 #3），立刻回滚该级。

## 5. Phase 3 · 换栈后立刻回移硬化（**新增，不可跳过**）

他们的 accel 没有我们这些天的东西，**其中 P0 自愈是必须的**——否则 A-78 那个
"休眠唤醒后黑屏、只能重启"会回来：

| 要回移的 | 来源 | 为什么必须 |
| --- | --- | --- |
| **A-79 P0 自愈链**（latch 超时 → 探面板是否在扫 → 重铺平面 → 同帧重试 → 停车 2 s → 自动复活；`gXeFlipUncertain` 2 s 上限） | `~/xegfx-log/A-79/` | **否则休眠/DPMS 后重演"黑屏+只能重启"** |
| flip/defer 开机默认 1 + bringup 双保险 | A-84 | 否则每次开机要手工开 |
| `debug.xegfxaccel_gt_mhz` | A-84 | 每档都要报"利用率" |
| `iop_tl` v2（`sub`/`vcnt` + `tl_raw`） | A-89 | 后续测量全依赖它 |
| `flip_failtest` 故障注入 | A-79 | 用来验证自愈真的能救 |

**门 3**：回移后**先测休眠/DPMS ×3**（配合 `flip_failtest` 注入）。门 = 画面回来、`flips` 恢复、
不需重启。**这一步比性能更重要**。

## 9. 回滚

1. 清 NVRAM 键（`nvram -d xegfx-disp-kms / -d xegfx-disp-bootmode`）+ 重启。
2. 插件换回 A-80 件（热换）。
3. 五件套回滚（`~/xegfx-log/A-83/backup/` 六个 kext + KC）+ 重启。
4. EFI 整份恢复（最后手段）；`nvram xeintelfb-starts=%00`。
