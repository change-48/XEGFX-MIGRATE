# Gate 4 · A-49 执行提示词：打开 defer 闸门，让 GPU 直接输出（一处判定）

> 目标：**去掉每帧的像素拷贝**，让面板直接扫描 CoreAnimation 合成的那块 surface。
>
> 依据链已完整：
> - A-42 起 `boot-armed: 6/6 … iop_xe_flip=1 + iop_xe_defer=1`，K9b 已武装；
> - A-46 证 `iop_xe_defer_queued = 0`，因为闸门 `q.pitch == P` 不成立（12480 vs 12544）；
> - A-47 已把 **stride 随 SURF 一起写** 的代码放进 `nvAccelXeFlipArm`（`:1775-1791`），但 arm 从未被进入 → 死代码；
> - `nvAccelIopHome()` 对非 NVRM 面板直接 return（`:3866`），无需处理归位。
>
> **所以只剩一处：把 defer 块里的那个等号放宽。** 改完 A-47 的死代码立刻变成活代码。

---

## 0. 为什么必须放宽（而不是改别处）

```c
// nvrm-accel.cpp:2471 之前，performTransaction() 的 defer 块
if (qr == kIOReturnSuccess && q.kva && q.pitch == P && q.height &&
    W == q.width && H == q.height && s->getPixelFormat() == 0x42475241u) {
        nvAccelXeFlipDeferQueue(this, s, W, H, P);   /* ← 只有到这里才会 arm */
```

- `P` = CA 的 IOSurface 行距 = **12544**（3120×4=12480，按 256 字节对齐补到 12544）
- `q.pitch` = 固件控制台行距 = **12480**，且它**不是实时读的**：`askFramebufferForScanout → nvScanoutInfo`，
  只有 NVRMFB 实现，我们走"描述启动光圈"的兜底 → 恒为 12480
- 所以这个等号在本机**永远不成立**，而把它写到 arm 里也没用（A-47 已证）

放宽的条件要收得很紧：**只有 P 是 64 的整数倍、且 P/64 装得进 11 位时才允许**（否则不写 stride 就会扫错）。

## 3. 唯一改动（一处判定）

把：

```c
        if (qr == kIOReturnSuccess && q.kva && q.pitch == P && q.height &&
            W == q.width && H == q.height && s->getPixelFormat() == 0x42475241u) {
```

改成：

```c
        /*
         * The scanout answer carries the firmware console's row pitch (12480 here), while
         * CoreAnimation allocates its IOSurface rows 256-byte aligned (3120*4 = 12480 -> 12544).
         * On the 2560-wide panels this was written for the two are equal (2560*4 = 10240 = 256*40),
         * so the flip never had to touch PLANE_STRIDE.  On a 3120-wide panel they differ, and the
         * equality below then rejects every frame: the deferred flip never runs and each frame is
         * copied by the CPU instead (4.4 ms at 3120x2080, plus WindowServer blocking on
         * waitUntilCompleted every frame -- measured 666/669 samples on 2026-11-01).
         *
         * nvAccelXeFlipArm() already programs PLANE_STRIDE together with PLANE_SURF, so allow the
         * arm when the surface pitch is one the register can hold.  Anything else keeps the copy.
         */
        const BOOL pitchArmable = (P == q.pitch) ||
            (P % 64u == 0u && (P / 64u) <= 0x7FFu);
        if (qr == kIOReturnSuccess && q.kva && pitchArmable && q.height &&
            W == q.width && H == q.height && s->getPixelFormat() == 0x42475241u) {
```

自检：

```bash
grep -n "pitchArmable" $F            # 期望 2 处
grep -c "q.pitch == P" $F            # 期望 0（已被替换）
```

**门 3：`pitchArmable` 2 处、旧等号 0 处。**

> 不要动 `nvAccelXeFlipArm`（A-47 的 stride 代码已经正确）、不要动拷贝路径、不要动 HOME。

## 5. 判决

```bash
L=~/xegfx-log/A-49
for i in $(seq 1 40); do grep -qE "OK: frames are reaching the panel|WARN" /var/log/xegfx-bringup.log 2>/dev/null && break; sleep 6; done
sudo tail -4 /var/log/xegfx-bringup.log

# 若 iop_ok 为 0，按 A-44 结论 6 重启 WS 一次
if [ "$(sudo sysctl -n debug.xegfxaccel_iop_ok)" = "0" ]; then
  sudo launchctl kickstart -k system/com.apple.WindowServer
  sleep 20
fi

echo "=== 关键计数 ==="
for k in iop_ok iop_xe_flips iop_xe_flip_miss iop_xe_flip_fail iop_xe_defer_queued iop_xe_defer_dropped iop_copy_sum_us; do
  printf "%-24s %s\n" "$k" "$(sudo sysctl -n debug.xegfxaccel_$k 2>/dev/null)"
done | tee $L/counters.txt

echo "=== 10 秒：帧 / 拷贝是否还在长 ==="
a=$(sudo sysctl -n debug.xegfxaccel_iop_ok); c=$(sudo sysctl -n debug.xegfxaccel_iop_copy_sum_us)
sleep 10
b=$(sudo sysctl -n debug.xegfxaccel_iop_ok); d=$(sudo sysctl -n debug.xegfxaccel_iop_copy_sum_us)
echo "fps=$(( (b-a)/10 ))   copy_delta_us=$((d-c))"
```

判读：

| 现象 | 结论 |
| --- | --- |
| `iop_xe_flips` 增长、`copy_delta_us` ≈ 0、画面正常 | **GPU 直接输出成立** ← 目标 |
| `iop_xe_flips` 增长但画面**斜切/撕裂** | stride 与 surface 不匹配 → 立即回滚 |
| `iop_xe_flip_miss` 增长、`xe_flips` 为 0 | arm 仍失败（别的条件），贴 `counters.txt` |
| 画面冻结在最后一帧 | arm 反复失败而 copy 被跳过 → **立即回滚**（重启即可恢复） |
