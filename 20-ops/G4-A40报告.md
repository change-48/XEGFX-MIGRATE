## 6. 判决（§6 A~D 原文）

`results`（core 0.0.46 + Display 0.5 + Accel 0.1 已载入）：


**一处异常**：`sysctl -w debug.xegfxaccelfb=3` 回显 `1 -> 1`（首次从 0 写到 1 时回显 `0 -> 1`）。**写 3 没有生效，停在 1**，与铁律 5 的期望不符，如实记录。

kickstart 后四次 abort（launchd 原文）：

```
23:19:59 WindowServer [3187] exited ... OS_REASON_COREANIMATION | Metal failed to specialize fragment function, ran for 44989ms
23:20:40 WindowServer [3230] exited ... OS_REASON_COREANIMATION | ..., ran for 40433ms

23:22:01 WindowServer [3330] exited ... OS_REASON_COREANIMATION | ..., ran for 44301ms
```

崩溃报告 `termination` 字段（10-30 的同类报告，签名一致）：

```
namespace: COREANIMATION   code: 7
details: function=fixed_frag_lph_cph spec=Xh
         native emitter: float32 bit literal f0x7fc00000 used as non-float type Half
```

NVMTL 侧原文：

```
NVMTL: newFunctionWithDescriptor: "fixed_frag_lph_cph" specializedName "Xh"
NVMTL: named constants: fixed_frag_lph_cph applied 60 of 60, merged 60
NVMTL: function constants: re-translate FAILED: native emitter: float32 bit literal f0x7fc00000 used as non-float type Half
NVMTL: newFunctionWithName:constantValues: "fixed_frag_lph_cph" — native emitter: float32 bit literal f0x7fc00000 used as non-float type Half
```

**A)** WS 单实例、每次活 36–45 s 后被杀（A-39 是 8–15 s）。
**B)** `OS_REASON_COREANIMATION` 4 次、`native emitter: float32` 24 次（每个实例循环 6 轮后死）。
**C)** `vmmap WS | grep -c nvmtl` = **0**（vmmap 视图里看不到映射，但 NVMTL 日志确实由 WS 进程打印；以日志为准）。
**D)** 采样**无效**：`sample` 抓到的 3253 在 2 秒窗口内被杀，`ws.txt` 仅 689 行，`MTL=0 SW=0 CompSW=0`——不是"GPU 合成为零"的证据，是采样没采到。

**根因定位（给下一关的唯一落点）**：

```
translator/translator/src/native/emitter/types.rs:545
    LlValue::Float32Bits(bits) => match self.resolve_type(ty)? {
        LlType::Float => self.const_float32_bits(*bits),
        other => Err(format!(
            "native emitter: float32 bit literal f0x{bits:08x} used as non-float type {other:?}"
        )),
    },
```

`Float32Bits` 只认 `LlType::Float`，**没有 `LlType::Half` 分支**；而 CA 的 `fixed_frag_lph_cph` 把 `0x7fc00000`（f32 NaN）当 Half 常量传进来。同文件紧邻的 `LlValue::Float` 分支是有 `LlType::Half => self.const_float16_bits(f32_to_f16_bits(...))` 的，`HalfBits` 也有——**只有 `Float32Bits` 这一支漏了**。
