# Gate 4 · A-41 执行提示词：给转换器补上缺失的 `LlType::Half` 分支（一处，四行）

> A-40 已经把根因定到**一行**：
>
> ```
> translator/translator/src/native/emitter/types.rs:542
> LlValue::Float32Bits(bits) => match self.resolve_type(ty)? {
>     LlType::Float => self.const_float32_bits(*bits),
>     other => Err("native emitter: float32 bit literal f0x… used as non-float type {other:?}"),
> },
> ```
> `Float32Bits` **只认 Float**；而紧邻的 `LlValue::Float` 分支**有 Half 处理**：
> `LlType::Half => self.const_float16_bits(f32_to_f16_bits(*value as f32))`。
> CA 的 `fixed_frag_lph_cph` 正是把 f32 位型 `0x7fc00000` 当 Half 传进来 → 这条分支报错 → CA abort。
>
> **本关只补这一支，写法照抄相邻分支。** 零 kext、零 EFI、零 reboot（translator 是用户态 dylib）。

---

## 0. 现状与依据

```
A-40 收尾：plugin/ 与上游 xe-2.6.2 tip 一致（补上了 NVMTL_XE_CB_BARRIER 那段）

native emitter 每个实例 24 次，签名不变：f0x7fc00000 used as non-float type Half
```

`types.rs` 里三兄弟的现状（已逐行核对）：

```rust
LlValue::Float(value)  => { LlType::Float => const_float32(value),  LlType::Half => const_float16_bits(f32_to_f16_bits(value)) }  ✅ 有 Half
LlValue::Float32Bits  => { LlType::Float => const_float32_bits(bits) }                                                              ❌ 缺 Half
LlValue::HalfBits     => { LlType::Half  => const_float16_bits(bits) }                                                              （只认 Half，正确）
```

helper 都在同一文件里：`const_float32_bits`（:1020）、`const_float16_bits`（:1036）、`f32_to_f16_bits`（相邻分支已在用）。

## 2. 唯一改动（四行）

文件：`~/src/NvGfx-xe-2.6.2/translator/translator/src/native/emitter/types.rs`

把：

```rust
            LlValue::Float32Bits(bits) => match self.resolve_type(ty)? {
                LlType::Float => self.const_float32_bits(*bits),
                other => Err(format!(
                    "native emitter: float32 bit literal f0x{bits:08x} used as non-float type {other:?}"
                )),
            },
```

改成：

```rust
            LlValue::Float32Bits(bits) => match self.resolve_type(ty)? {
                LlType::Float => self.const_float32_bits(*bits),
                /* AIR carries an f32 bit pattern for a half constant when Core Animation
                 * specializes fixed_frag_lph_cph (spec "Xh"): it hands us 0x7fc00000, a float32
                 * quiet NaN, declared Half.  The Float arm above already narrows to half this
                 * way; do the same here instead of refusing the module. */
                LlType::Half => self.const_float16_bits(f32_to_f16_bits(f32::from_bits(*bits))),
                other => Err(format!(
                    "native emitter: float32 bit literal f0x{bits:08x} used as non-float type {other:?}"
                )),
            },
```

自检：

```bash
grep -n -A8 "LlValue::Float32Bits(bits) => match" $F
# 期望看到三支：Float / Half / other
grep -c "const_float16_bits(f32_to_f16_bits(f32::from_bits" $F    # 期望 1
```

**门 2：三支齐全、且新行只有 1 处。** 不要顺手改 `HalfBits`/`BFloatBits`。

## 5. 判决：重启 WS，看 `native emitter` 归零

```bash
L=~/xegfx-log/A-41
( sudo log stream --predicate 'eventMessage CONTAINS "NVMTL" OR eventMessage CONTAINS "NMXAccel" OR eventMessage CONTAINS "AGDC" OR process == "WindowServer"' > $L/stream.log 2>&1 & )
sleep 2

sudo /usr/bin/kmutil load -b org.watchthelight.XeGfx
sudo sysctl -w debug.xegfx_wdog=60 >/dev/null
sudo sysctl -w debug.xegfx_stage=7 >/dev/null
sleep 22
sudo sysctl -b debug.xegfx_results | od -A n -t d4 | tee $L/results.txt     # 期望 0 1 1 1 1 1 1 1

sudo /usr/bin/kmutil load -b org.watchthelight.XeGfxAccel; sleep 3
sudo sysctl -w debug.xegfxaccelfb=1        # 本版本读回恒 1；scanout 门由内部 how 决定，A-38/A-39 用 1 也能起
sleep 4
sudo sysctl debug.xegfx_agdc; sudo sysctl debug.xegfx_agdc_fbmap | tee $L/agdc.txt

sudo launchctl kickstart -k system/com.apple.WindowServer
sleep 40

echo "=== A) native emitter（本关的核心判据）==="
grep -c "native emitter" $L/stream.log
echo "=== B) COREANIMATION 崩溃次数 ==="
grep -c "OS_REASON_COREANIMATION" $L/stream.log
echo "=== C) WS 存活 ==="
pgrep -x WindowServer | wc -l; ps -o etime=,pid= -p "$(pgrep -x WindowServer)" 2>/dev/null
echo "=== D) 特化是否成功 ==="
grep -E "specialized with|re-translate FAILED|FALLING|specializedName" $L/stream.log | tail -8
echo "=== E) 合成栈（活过 40 s 才有意义）==="
sudo sample $(pgrep -x WindowServer) 2 -file $L/ws.txt >/dev/null 2>&1
echo "MTL=$(grep -c 'CA::MTL' $L/ws.txt) SW=$(grep -cE 'CA::OGL::SW|scanline|draw_polygon' $L/ws.txt) CompSW=$(grep -c 'CompositorSW::CompositeLayersToDestination' $L/ws.txt)"
echo "=== F) 加速器统计 ==="
sudo ioreg -l -w0 -r -c NMXAccel 2>/dev/null | grep -oE '"(surfaceCount|bufferSwapCount|bufferFlipCount|contextGLCount)"=[0-9]+' | tee $L/perfstats.txt
```

判读：

| 结果 | 结论 |
| --- | --- |
| `native emitter` = **0** 且 `specialized with N constant(s)` 出现 | **这一支修对了** → 看 WS 是否活过 40 s |
| `native emitter` = 0、WS 活过 40 s、`MTL > 0` | **Gate 4 第 3 条达成** |
| `native emitter` 仍 > 0，但 `bits` 变了（例如 `0x3c00`） | 还有别的类型不匹配，**贴新的 bits 值** |
| WS 崩在别处 | 新签名，贴 `.ips` 的 `termination` + `details` |
