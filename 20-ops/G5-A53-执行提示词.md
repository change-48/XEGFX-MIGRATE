# Gate 5 · A-53 执行提示词：让 scanout 变成 12544 行距（分两次构建，先只分配不动平面）

> 目标：**让 `q.pitch == P` 自然成立**，从而上游的零拷贝延迟 flip 原样工作 —— 不掰闸门（A-49 的冻屏就是这么来的），
> 而是把前提补齐。
>
> 已核实的三件事：
> 1. 兜底回答在 **accel 内部**（`NVAccel::describeBootFramebuffer`），不必改 FB；
> 2. **stolen 有 128 MB**（`xnStolenEnd - DSM`），固件控制台只占 25.96 MB，**空间充足**；
> 3. 12544 × 2080 = **26,091,520 B**，比现在多 130 KB。

---

## 0. 分两次构建（这是本关的核心纪律）

| 构建 | 做什么 | 失败时的影响 |
| --- | --- | --- |
| **第一次** | 只**分配 + 映射 + 报告**（sysctl 读出地址），**绝不碰平面寄存器** | **零**：画面、帧流完全不受影响 |
| **第二次** | 确认第一次成功后，才把平面指过去、按 12544 回答 | 可能花屏/黑屏，但重启即恢复 |

**第一次没通过就绝对不做第二次。**

---

## 1. 第一次构建：只分配，不动平面

文件：`~/src/NvGfx-5a19a73f36249efb99c44c3f9cb34603ef0c0eb8/kexts/NVRM/accel/nvrm-accel.cpp`

### 1.1 新增状态与分配函数（放在 `describeBootFramebuffer` 之前）

```c
#ifdef NMX_XEGFX
// A scanout the accelerator owns, laid out at the compositor's row pitch.
//
// CoreAnimation aligns IOSurface rows to 256 bytes: a 3120-wide panel asks for 12544 while the
// firmware console scans 12480, and the deferred flip in performTransaction() refuses to run
// unless q.pitch == P.  The boot aperture cannot simply be widened -- it is 25,958,400 B and
// 12544 x 2080 needs 26,091,520 -- so take a buffer of our own from the GGTT slots XeGfx already
// reserves, describe it at 12544, and point the plane at it once.  Stolen has 128 MB; this is 25.
struct NvScanoutBuf {
    IOBufferMemoryDescriptor *md;
    void    *kva;
    IOPhysicalAddress phys;
    unsigned long long bytes;
    unsigned pitch;              /* 12544 */
    unsigned ggtt;               /* slot 0's GGTT offset */
    bool     live;
};
static NvScanoutBuf gScanout = {};
static unsigned gScanoutWant = 0;      /* 0 = off, 1 = describe only, 2 = also take the plane */
static unsigned gScanoutState = 0;     /* 0 idle, 1 mapped, 2 plane taken, 3 failed */

static bool nvScanoutAlloc(void)
{
    if (gScanout.live) return true;
    const unsigned w = 3120, h = 2080, pitch = 12544;
    const unsigned long long bytes = (unsigned long long)pitch * h;
    if (!bytes || bytes > 64ull * 1024 * 1024) { gScanoutState = 3; return false; }

    IOBufferMemoryDescriptor *md = IOBufferMemoryDescriptor::inTaskWithOptions(
        kernel_task, kIODirectionOutIn | kIOMemoryPhysicallyContiguous, (vm_size_t)bytes, 4096);
    if (!md) { ALOG("scanout: %llu B allocation failed", bytes); gScanoutState = 3; return false; }

    // The GGTT slot comes from the same pool the flip uses; one slot is enough for a scanout.
    unsigned long long ggtt[1] = { 0 }; unsigned n = 0;
    if (nvAccelResidentCall("xgFlipInit", (void *)(uintptr_t)bytes, (void *)(uintptr_t)1,
                            ggtt, &n) != kIOReturnSuccess || n == 0) {
        ALOG("scanout: xgFlipInit refused a %llu B slot", bytes);
        md->release(); gScanoutState = 3; return false;
    }

    unsigned long long *phys = (unsigned long long *)IOMalloc(sizeof(unsigned long long) * 8192);
    unsigned npages = 0;
    if (!phys) { md->release(); gScanoutState = 3; return false; }
    IOByteCount off = 0;
    while (off < bytes && npages < 8192) {
        IOPhysicalAddress pa = md->getPhysicalSegment(off, &segLen, 0);   /* see note below */
        if (!pa || !segLen) break;
        for (unsigned long long q = 0; q < segLen && npages < 8192; q += 4096)
            phys[npages++] = ((unsigned long long)pa + q) & ~0xfffull;
        off += segLen;
    }
    IOReturn r = (npages < ((bytes + 4095) >> 12)) ? kIOReturnNoSpace :
        nvAccelResidentCall("xgFlipMap", (void *)0, phys, (void *)(uintptr_t)npages, (void *)(uintptr_t)bytes);
    IOFree(phys, sizeof(unsigned long long) * 8192);
    if (r != kIOReturnSuccess) {
        ALOG("scanout: xgFlipMap refused (%u pages, 0x%x)", npages, (unsigned)r);
        md->release(); gScanoutState = 3; return false;
    }

    gScanout.md = md; gScanout.kva = md->getBytesNoCopy(); gScanout.phys = md->getPhysicalSegment(0, nullptr, 0);
    gScanout.bytes = bytes; gScanout.pitch = pitch; gScanout.ggtt = (unsigned)ggtt[0]; gScanout.live = true;
    gScanoutState = 1;
    ALOG("scanout: %llu B at kva %p phys 0x%llx ggtt 0x%x pitch %u (%u pages, slot 0)",
         bytes, gScanout.kva, (unsigned long long)gScanout.phys, gScanout.ggtt, pitch, npages);
    return true;
}
#endif
```

> **`getPhysicalSegment` 的签名**：本树里调用形如 `md->getPhysicalSegment(off, &len)`。
> 按现场实际签名改（有的版本只收 offset 和 flag）。**编译报错就按报错改调用方式，不要改逻辑。**

## 2. 第二次构建：把平面指过去（仅在门 A 通过后）

1. `describeBootFramebuffer` 在 `gScanout.live` 时改为按新缓冲回答：

```c
        if (gScanout.live && gScanoutState >= 2) {
            r->kva = gScanout.kva; r->phys = gScanout.phys; r->width = 3120; r->height = 2080;
            r->pitch = gScanout.pitch; r->actualSize = r->size = gScanout.bytes;
            return kIOReturnSuccess;
        }
```

2. 进入 `state=2` 时（`debug.xegfxaccel_scanout=2`）：
   - 先把**当前固件画面整块拷进新缓冲**（按 12544 行距逐行拷 12480 字节，源是 `fBootFBMap`），避免黑屏；
   - 再 `gDispMmio[NV_PLANE_STRIDE_A/4] = 196;` 然后 `gDispMmio[NV_PLANE_SURF_A/4] = gScanout.ggtt;`
     （**先 stride 后 surf**，与 A-47 的顺序一致）。

3. 重启后验证：

```bash
sudo sysctl debug.xegfxaccel_iop_ok debug.xegfxaccel_iop_xe_flips debug.xegfxaccel_iop_xe_defer_queued debug.xegfxaccel_iop_copy_sum_us
a=$(sudo sysctl -n debug.xegfxaccel_iop_ok); c=$(sudo sysctl -n debug.xegfxaccel_iop_copy_sum_us); sleep 10
b=$(sudo sysctl -n debug.xegfxaccel_iop_ok); d=$(sudo sysctl -n debug.xegfxaccel_iop_copy_sum_us)
echo "fps=$(( (b-a)/10 )) copy_delta=$((d-c))"
```

**门 B（本关目标）：`iop_xe_flips > 0` 且 `copy_delta ≈ 0`，画面正常。**

## 5. 铁律

1. **第一次构建绝不写 `PLANE_SURF` / `PLANE_STRIDE`。**
2. 门 A 不过就不做第二次。
3. 平面写入顺序：**先 stride，后 surf**。
4. 构建失败不改编译参数；按报错改调用签名。
5. 画面异常 → 重启（不要在线调寄存器）。
