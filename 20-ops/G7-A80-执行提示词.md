# Gate 7 · A-80 执行提示词：page-off 落地（插件私有拷贝 lazy → coherent + CCS A/B）——前人 +24 翻/秒的最后一段

> 目标：A-79 把 accel 侧通道全部铺好（selectors 5–8、CPU 锁钩子 op 0、统计，零调用零回归，
> 符号已验证可链接），**P2b 是现在唯一挡在 +24 翻/秒前面的东西**。本关把插件侧补上：
> 私有 optimal-tiling 图像（ARL 上自动带 CCS_E 压缩）→ 合成后标 current（selector 5）→
> CPU 加锁/翻页前 page-off 拷回页面（selector 6/7 循环）→ **先 lazy、后 coherent** →
> noccs A/B 量化我们自己的压缩收益。
>
> 必读：`G7-A79报告.md`（§3.2 已就位的 accel 侧、§7 路标）、`G7-A78报告.md`、
> `AI-远程连接说明.md`、`AI-远程调试作业说明.md`。

## 0. 前人机制（照抄，A-79 已把 accel 半边装好）

| 环节 | 做法 | 出处 |
| --- | --- | --- |
| 私有图像 | WS render target（**BGRA8、≥1024×600、非 scanout**）画进插件**私有 optimal-tiling 图像**而非线性页面；ARL（Xe-LPG `has_aux_map`）上 ANV 自动加 **CCS_E**（内存 +1/256） | page-off-and-compression.md |
| current 标记 | 每次合成后经 **selector 5** 把 surface 的 device cache 标 current（accel 侧已就位，含锁计数退让：被锁的面不标、标后发现被锁就撤回） | 0024 §36.12（已装） |
| page-off 拷回 | CPU 加锁（op 0 钩子，≤300ms）或翻页/拷贝前（≤50ms）时：accel 等本 surface 合成 mark → 经 **selector 6**（wait，超时返回 `id<<32\|seq`）向插件 page-off 线程发活 → 线程把私有图像拷回页面 → **selector 7**（done）→ accel 重验后放行 | 同上 |
| 升级规则（lazy） | **先 lazy**：私有拷贝活 3 s / 被画 100 次才升级；哨兵 `/private/tmp/xemtl-pageoff-lazy` | 0026 |
| 退直画规则 | 1 s 内被 page-off >4 次、或变成 scanout 的 surface → 退回直画页面 | 同上 |
| coherent 规则（2c） | 私有拷贝只在「本进程唯一 root」时保留；新 root 不能做 view 就先退页；释放→写回全程持 surface 同步对象，新 root 交出前先等；活不到 2 s 或从没画过 → 不再建 | 同上 |
| 效果数字 | **58 → 82 翻/秒**（page-off 关 vs 默认）；genie lazy 60/59/48 → coherent **89/85/76** | logs/README.md |
| 开关 | `/Library/GPUBundles/.xemtl-no-pageoff`（跨重启）、`/private/tmp/xemtl-no-pageoff`、`-lazy`、`/private/tmp/xemtl-noccs`（下次 WS 启动 `INTEL_DEBUG=noccs`） | 0026 |

**本关的既有地基（全部 A-79 已验证）**：
- accel：selectors 5–8 + op 0 钩子 + `iop_xe_po` 统计 + 锁计数退让，零调用零回归；
- 插件：内部 cb 不参与 WS marks（`nvmtl_internal_cb`，**page-off 线程的拷贝 cb 必须走这条通道**）；
- relayout 的「同页换布局 + GPU 拷贝」能力在源码里（受 `xemtl-no-tile4` 关闭）——私有图像与页面之间的拷贝形态与它同源；
- nowait 哨兵已进开机自启；flip 自愈链（停车 2 s + 自动复活）就位。

## 2. P2b · lazy 版私有拷贝（先做）

### 2.1 插件侧改动（0026 的 page-off 半边）

| 组件 | 内容 |
| --- | --- |
| 私有图像创建 | `nvmtl_surface_image_create()` 的 `<wtl>` 分支：对合格面（BGRA8、≥1024×600、非 scanout——判据照 0026）不再做线性别名，改为**私有 optimal-tiling 图像**；创建失败回落线性（不留半私有状态） |
| current 标记 | 合成提交路径（`after_commit`/EventSync 已有钩子）对本帧触碰的合格面发 **selector 5** |
| page-off 线程 | 新线程循环 **selector 6**（accel 发活）→ GPU 拷贝私有图像→页面（**内部 cb 通道**，照 relayout 的两跳 blit 形态）→ **selector 7** 报完成；退出条件照 0026（detach/超时） |
| lazy 规则 | 活 3 s / 画 100 次才升级私有（0026 判据）；升级前的面照旧直画页面 |
| 哨兵 | `.xemtl-no-pageoff`（两级路径都读，节流 1 s 重读）、`-lazy` |

## 3. P2c · coherent 规则 + CCS A/B

### 3.1 规则补齐（0026 一致性全套）

唯一 root 保留 / 新 root 退页 / 释放→写回持同步对象 / 活不到 2 s 不再建 / >4 次/s 退直画
（accel 侧的锁计数退让已装，本关让它第一次有调用者）。

### 3.2 CCS A/B（照前人方法）

```bash
# 默认（CCS on）3 轮拖动 → touch /private/tmp/xemtl-noccs + kickstart WS → noccs 3 轮
~/xegfx-log/A-74/fps-probe2.sh 25 | tee ~/xegfx-log/A-80/fps-ccs-on-rN.txt
sudo touch /private/tmp/xemtl-noccs && sudo launchctl kickstart -k system/com.apple.WindowServer
# （重新登录后）3 轮 → 删哨兵 + kickstart 恢复
```
