# Gate 4 · A-22 执行提示词（让这个头会描述自己的 scanout）

> 用法：把本文件全文作为一条消息发给执行会话。执行会话不需要任何前置上下文。
> **只加 ~15 行代码到一个类里，重编一个 kext。** 不动探针分、不动别的 kext、不动 OpenCore。

---

## 0. 现在的闸门（A-21 已把前一道打开）

```
NMXAccel: .Display_boot: XeGfxIntelFramebuffer accepted as head 4
NMXAccel: heads published 0x10, registered 0x10, piped 0x10
sysctl debug.xegfxaccelfb=3
NMXAccel: NVDisplayPipe::initFramebufferResource: framebuffer would not describe its scanout (0xe00002c7)
```

`0xe00002c7` = `kIOReturnUnsupported`。根因已到符号级：

| 类 | `getPixelInformation` | `getCurrentDisplayMode` |
| --- | --- | --- |
| `XeGfxIntelFramebuffer`（现役） | **未实现** → 转发给 `IONDRVFramebuffer` | **未实现** → 同上 |
| `NMIntelFB` | ✅ 自己实现（11 行） | ✅ 自己实现（1 行） |

本机 `IGPU` 没有可用 NDRV 实例，`IONDRVFramebuffer` 没人应答 → 返回 Unsupported →
accel 拿不到 scanout 的 phys/尺寸/行距。**把这两个方法补上就通了。**

## 1. 要移植的原文（来自 `kexts/NMIntelFB/intelfb.cpp:463`，已核实）

```c
IOReturn NMIntelFB::getPixelInformation(IODisplayModeID mode, IOIndex depth,
                                        IOPixelAperture aperture, IOPixelInformation *pi)
{
    if (mode != 1 || depth != 0 || aperture != kIOFBSystemAperture || !pi) return kIOReturnUnsupportedMode;
    bzero(pi, sizeof(*pi));
    pi->bytesPerRow = fRowBytes; pi->bytesPerPlane = 0; pi->bitsPerPixel = 32; pi->pixelType = kIORGBDirectPixels;
    pi->componentCount = 3; pi->bitsPerComponent = 8;
    pi->componentMasks[0] = 0x00FF0000; pi->componentMasks[1] = 0x0000FF00; pi->componentMasks[2] = 0x000000FF;
    strlcpy(pi->pixelFormat, IO32BitDirectPixels, sizeof(pi->pixelFormat));
    pi->activeWidth = fWidth; pi->activeHeight = fHeight;
    return kIOReturnSuccess;
}
```
以及声明处的三行（`:212-214`）：
```c
IOReturn getPixelInformation(IODisplayModeID mode, IOIndex depth, IOPixelAperture aperture, IOPixelInformation *pi) override;
IOReturn getCurrentDisplayMode(IODisplayModeID *mode, IOIndex *depth) override { *mode = 1; *depth = 0; return kIOReturnSuccess; }
IOReturn getStartupDisplayMode(IODisplayModeID *mode, IOIndex *depth) override { return getCurrentDisplayMode(mode, depth); }
```

## 2. 目标类缺什么（已核实）

`XeGfxIntelFramebuffer`（`kexts/XeGfxIntelFB/intelfb.cpp:156` 起）有：
`fEdid[256]`、`fEdidLen`、`fHz16`、`fT[T_COUNT]`（`T_HVIS/T_VVIS/...`）、`fTValid`、`fDimSurf`。
**没有 `fWidth / fHeight / fRowBytes`** —— 这就是要补的三个成员。

尺寸与行距从哪来：`xifbMeasureTiming()` 里已经读了
`conf = r[0x70008/4]`、`plane = r[0x70180/4]`、`size = r[0x70190/4]`。
`PLANE_SIZE` 的布局是 **低 16 位 = width-1、高 16 位 = height-1**；`PLANE_STRIDE(0x70188)` 单位是 **64 字节**。

## 3. 改动（三处，都在 `kexts/XeGfxIntelFB/intelfb.cpp`）

### 3.1 加三个成员（类声明里，紧跟 `fDimSurf` 之后）

```c
    uint32_t fW = 0, fH = 0, fRowBytes = 0;    // the raster we publish to the accelerator
```

### 3.2 在 `xifbMeasureTiming()` 读到 `size` 的地方，把这三个填上

```c
    // 与 scanout 完全一致：尺寸取 PLANE_SIZE，行距取 PLANE_STRIDE（单位 64 B）
    fW = (size & 0xFFFFu) + 1;
    fH = (size >> 16) + 1;
    fRowBytes = (r[0x70188 / 4] & 0xFFFFu) * 64u;
    XIFBLOG("scanout geometry for accel: %ux%u rowBytes %u", fW, fH, fRowBytes);
```
> 若 `xifbMeasureTiming` 里 stride 没读到，退一步用 `fW * 4`。**不要**用 `fT[T_HVIS]` 顶替宽度 ——
> 那是几何推算值，可能和 PLANE_SIZE 不一致；accel 要的是**真正在扫的那块**。

### 3.3 加三个方法（类里，挨着 `getAttributeForConnection`）

```c
    IOReturn getCurrentDisplayMode(IODisplayModeID *mode, IOIndex *depth) override
    { *mode = 1; *depth = 0; return kIOReturnSuccess; }

    IOReturn getStartupDisplayMode(IODisplayModeID *mode, IOIndex *depth) override
    { return getCurrentDisplayMode(mode, depth); }

    IOReturn getPixelInformation(IODisplayModeID mode, IOIndex depth,
                                 IOPixelAperture aperture, IOPixelInformation *pi) override
    {
        if (mode != 1 || depth != 0 || aperture != kIOFBSystemAperture || !pi) return kIOReturnUnsupportedMode;
        if (!fW || !fH || !fRowBytes) return kIOReturnUnsupported;      // 还没测量过：诚实拒绝
        bzero(pi, sizeof(*pi));
        pi->bytesPerRow = fRowBytes; pi->bytesPerPlane = 0; pi->bitsPerPixel = 32;
        pi->pixelType = kIORGBDirectPixels;
        pi->componentCount = 3; pi->bitsPerComponent = 8;
        pi->componentMasks[0] = 0x00FF0000; pi->componentMasks[1] = 0x0000FF00; pi->componentMasks[2] = 0x000000FF;
        strlcpy(pi->pixelFormat, IO32BitDirectPixels, sizeof(pi->pixelFormat));
        pi->activeWidth = fW; pi->activeHeight = fH;
        return kIOReturnSuccess;
    }
```

**不要动别的东西**：不改 `getAttributeForConnection`、不改 EDID/时序逻辑、不改类名、不改 depid
（depid 已是对的：280-281 行、`XEGF/0`、在 `IONDRVFramebuffer::start()` 之前）。

## 5. 验证

### 5.1 归属与几何没被破坏

```bash
ioreg -l -w0 2>/dev/null | grep -c "class XeGfxIntelFramebuffer"      # 1
ioreg -l -w0 2>/dev/null | grep -c "class IONDRVFramebuffer"          # 0
system_profiler SPDisplaysDataType | grep -E "Resolution|Online|Main Display"
sudo /usr/local/bin/xenative-ctl status | grep -E "SURF|STRIDE"
tail -6 /var/db/xegfx/fbgeom.log
```

### 5.2 关键：`0xe00002c7` 有没有消失

```bash
sudo /usr/bin/kmutil load -b org.watchthelight.XeGfx
sudo sysctl -w debug.xegfx_wdog=60 ; sudo sysctl -w debug.xegfx_stage=7 ; sleep 25
sudo sysctl -b debug.xegfx_results | od -A n -t d4
sudo sysctl -w debug.xegfxaccelfb=3
sudo log show --last 3m --predicate 'eventMessage CONTAINS "NMXAccel"' | tail -25
```
**读这几句**：
- 仍出现 `framebuffer would not describe its scanout (0xe00002c7)` → 方法没被调用或返回失败 →
  查 `XIFBLOG("scanout geometry for accel: ...")` 有没有打出来（没打 = `fW/fH/fRowBytes` 没填上）
- 出现 `initFramebufferResource` 成功类日志、或 `0xe00002c7` 不再出现 → ✅ 进 5.3

### 5.3 Gate 4 的四条（本关第一次可能真的全部可达）

```bash
sudo vmmap "$(pgrep -x WindowServer)" 2>/dev/null > ~/xegfx-log/A-22/vmmap-full.txt
grep -ci nvmtl ~/xegfx-log/A-22/vmmap-full.txt        # 期望 > 0
system_profiler SPDisplaysDataType | grep -i metal
ls -t /Library/Logs/DiagnosticReports/WindowServer*.ips 2>/dev/null | head -2
```

**测量纪律（前两轮都栽在这里）**：
- `sample WindowServer` 的 `CA::OGL::SW` 计数**只在与"桌面在动"同条件时可比**。静止桌面下两边都是 0，没有判别力。
  → 判"是否换了合成器"**用 `vmmap nvmtl > 0` + 有没有 `CompositorSW` 崩溃**，不要用静止桌面的 sample 计数。
- `powermetrics` 的列是 **`CPU ms/s`**（1000 = 一整个核），不是百分比。要在同一次开机、同状态下 A/B。

## 6. 铁律与禁忌（都是今天踩出来的）

1. **不要再 `launchctl kickstart -k` 任何 `kernelmanagerd` / `syspolicyd`** —— A-21 这么干把机器搞挂过一次
   （`IOHIDFamily` page fault panic）。审批门用 `-z` 绕。
2. **armed 之后 120 s 内不要重启**，否则等于自触发护栏回滚（会把 kext 全搬走并清空审批历史）。
3. **`kmutil` 在 `/usr/bin`**（`/usr/sbin/kmutil` 不存在）。
4. **探针分不许动**：`IGPUConsoleRange 65000 > XeGfxIntelFB 20001 > NMIntelFB 5000` 已验可用。
5. **`fbgeom` 的判据现在是 `ioreg | grep "class NMIntelFB"`**，别改回去 —— `ioreg -c` 在没有实例时会打整棵树，恒为真。
6. 不许改 OpenCore / boot-args；不许开 `debug.xegfxaccelfb` 以外的新开关。
